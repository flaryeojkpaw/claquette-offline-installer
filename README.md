# Claquette — Free Offline Installer

![Category](https://img.shields.io/badge/GIF_Tool-blue?style=flat-square)

## About

Claquette is a native macOS GIF and video tool for creating, editing, and optimizing animated GIFs. Record screen areas or windows to GIF, convert video files, edit frame timing and crop, and optimize file size for web use. Claquette's native macOS design and ease of use make it the preferred GIF creation tool for Mac users who need polished animated GIFs for documentation or social media.

## Common Problems & Limitations

- **macOS Only** — No Windows version
- **Commercial License** — Paid application from the Mac App Store
- **Advanced Editing** — Limited compared to dedicated video editors for complex animations
- **Large File Sizes** — High-quality GIFs from screen recordings can be large without optimization
